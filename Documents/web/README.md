# Sasami — tienda en React

Instalar y probar:  `npm install` y luego `npm run dev`
Publicar:           `npm run build` y subir la carpeta `dist/` (Netlify, Vercel, etc., en la raíz del dominio)

Qué editar:
- `src/config.js`      → WhatsApp, Instagram, horario, pagos, categorías, looks, preguntas frecuentes
- `public/productos.json` → catálogo (agregar prendas, `"vendido": true`)
- `public/img/`        → fotos (productos, categorias, looks, hero.png (logo con transparencia), hero-og.jpg (para compartir), quienes.jpg)
